## Стек и деплой
- Vercel (Hobby): статические `*.html` + serverless в `api/`. **Лимит 12 функций** (сейчас 11) и **2 ежедневных cron**:
  - `/api/cron/meeting-reminders` 06:00 UTC → `lib/morning.js` (напоминания о встречах, автоfollow-up, отзывы, обучение, «Итоги», недельный отчёт, дедлайны задач, пары, обновление настроек бота, дайджест 9:00);
  - `/api/cron/club-reminders` 15:00 UTC (18:00 МСК) → продление клуба, пары, пятничная сводка задач.
- Хранилище: Upstash Redis REST (`lib/store.js`, `store.command(...)`).
- Отложенные вызовы: QStash (`lib/qstash.js` → `POST /api/telegram/reminder`, заголовок `X-Reminder-Secret`). Адрес назначения передаётся **без** URL-кодирования (иначе QStash 400). Проверка владелицей: команда бота `/delaytest`.
- Tribute API — подписчики клуба (`lib/tribute.js`). ЮKassa — оплаты встреч/обучения через Telegram invoice.
- `telegram-web-app.js` лежит в репозитории (telegram.org блокируется в РФ).
- Деплой: коммит в `main` → Vercel собирает сам. Проверка: `gh api repos/metodsur/k-zhenshchine-mini-app/commits/$(git rev-parse HEAD)/status --jq .state` → `success`.
- Коммиты: `git -c user.name="Claude" -c user.email="noreply@anthropic.com" commit`, в конце сообщения строка `Co-Authored-By: Claude …`.
- Тесты: `node --test tests/*.test.js` (фейковые Redis/Telegram/QStash в `tests/helpers/fake-world.js`). Сейчас 103 теста, все зелёные — держать так.

## Бот (api/telegram/webhook.js)
Порядок: оплаты → callback-кнопки (`p:` пары → `lib/pairs.js`, `t:` задачи → `lib/tasks.js`) → `/setup`, `/delaytest` (владелица, `lib/bot-setup.js`) → задачи (`/tasks`, `/task`, ответы на сообщения задач) → согласие → `/master` → ответы на рассылки.
Команды в меню бота: `/space /master /tasks /task /start`. Меню обновляется каждое утро автоматически.

## Дашборд команды — `os.html` (вход: бот `/dashboard` → одноразовая ссылка → cookie)
Разделы: Сегодня, Задачи, HR (только владелица, `hr.view`), Итоги, CRM, Циклы, Мастера, **Пары**, **Эксперты**, **Доступы**, **База данных**, Календарь, Контент, Медийность, Площадки, Библиотека (+ скрытые: шаблоны, материалы обучения, инструкции Мастеров).
Роли/права — `lib/team.js` (owner, director = всё кроме team.manage и hr.view, analyst, manager, content, master).

### Задачи (`lib/tasks.js`, ключ `os:tasks`)
- Статусы todo/doing/done, комментарии, чек-лист, история; уведомления в бот; дедлайны утром; сводка по пятницам вечером.
- В боте: `/tasks` (владелица/директор — сводка по людям + все задачи кнопками), `/task Текст` или «➕ Новая задача» → выбор ответственного → срок. Комментарий = ответ (reply) на любое сообщение с задачей (карта `tmsg:<chat>:<msg>`). Последний комментарий выделен жирным и в боте, и в дашборде.
- Проверка (право `tasks.review` — владелица и директор): «👍 Утвердить» / «✏️ На правки» / «⛔ Брак» в карточке задачи в дашборде и кнопками в боте под выполненной задачей. Правки и брак требуют текста, возвращают задачу в работу и приходят ответственной. Повторное «Выполнено» снова ставит «Ждёт утверждения». Поля `review`, `reviews`.
- Вложения (`attachments`): фото, видео, файлы, тексты, ссылки. Файлы хранятся в Telegram (file_id): из дашборда до 3 МБ (бот отправляет файл загрузившему себе в чат), больше — ответом в боте на сообщение с задачей. Просмотр — `GET /api/os/file?task=…&a=…` (сессия дашборда; inline только фото/видео; больше 20 МБ бот присылает файл в Telegram). Голая ссылка ответом в боте = вложение-ссылка.
- План от 07.10 (18 задач на Анастасию) импортируется один раз (`lib/seed-plan.js`).

### Доступы (`lib/vault.js`, ключ `os:vault`)
- Сервис, категория, ссылка на кабинет, логин, пароль (AES-256-GCM, в список не отдаётся; «Показать» на 30 с / «Копировать»; каждый просмотр логируется), «У кого есть доступ», заметки (выделены жирной плашкой).
- Владелица и директор (`vault.all`) видят всё и удаляют; остальные — только записи, где указаны их имена.

### База данных (`lib/database.js`, ключ `os:db`)
- Записи: название, папка, описание + файл (фото/видео/аудио/документ; аудио — и как трек или голосовое в боте, играет прямо в карточке), ссылка и/или текст. Видят и добавляют все с `os.workspace`; удаляет автор, владелица или директор (`tasks.review`).
- Файлы — в Telegram, как вложения задач: из дашборда до 3 МБ (`upload`), больше — «Прислать через бот»: бот пишет сообщение, файл ответом на него (или следующим сообщением в течение часа, состояние `db_file`) попадает в запись (карта `dbmsg:<chat>:<msg>`). Просмотр — `GET /api/os/file?db=<id>`.

### Пары на ритуал (`lib/pairs.js`)
- Раунд = созвон клуба (раз в 2 недели; расписание задаётся в дашборде «Пары»). После созвона бот зовёт подписчиц клуба: «Подберите мне пару» / «Выберу сама». Автоподбор через N минут (QStash) + страховка: подбор запускается при открытии страницы/дашборда после срока.
- Критерии: новая пара каждый раз (главное), общие ресурсы, похожие «Мои задачи» (ключевые слова, никому не показываются), город/часовой пояс, новенькая + опытная. Нечётное — тройка. Через 3 дня — напоминание.
- «🧪 Тестовый раунд» в дашборде: только команда, подбор через 10 мин, удаляется без следа.

### Пригласи подруг (`lib/referrals.js`)
- У каждой своя ссылка-приглашение в бесплатный канал (бот создаёт её с именем `ref:<id>`, хранится в `ref:links`); в «Обо мне» блок «Пригласи подруг» (`/api/auth/me` с `action: "referral"`).
- Засчитывается только новая женщина (первое вступление в канал) и только один раз — по первой ссылке (`ref:by`).
- 10 приглашённых → две недели клуба в подарок: одноразовая ссылка в группу клуба, сообщение ей и команде. Вечерний cron за 2 дня напоминает, а по окончании без подписки Tribute удаляет из группы (ban + unban). Нужны права бота в группе клуба: приглашать и удалять участников.
- 20 приглашённых → может стать экспертом в День эфиров: сообщение ей (с кнопкой на анкету) и команде (один раз).

### Анкета эксперта (`expert.html`, `kind: "expert"` в `lib/handlers/application.js`)
- День эфиров: вторник 16:00–18:30 МСК, 5 эфиров по 30 минут подряд (слоты 16:00…18:00).
- Вступление о пространстве → 10 вопросов (кто ты, чем служить пространству, опыт выступлений, кейсы, ссылка на «Уровни», тема, этап пути, польза, продукт, слоты) → 5 ценностей, все обязательны. Ответы + число приглашённых приходят команде в бот и в список `applications`, заметка в CRM. Сообщение получают все с правом `alerts` (владелица и директор Анастасия, если она добавлена в команду с её Telegram ID). Карточка сама появляется в дашборде «Эксперты» (коллекция `experts` в `lib/os-collections.js`, видят владелица и директор, `tasks.review`): Новая анкета → Созвон → Слот назначен (дата + время, попадает в Календарь) → Эфир проведён / Не сейчас. Вход: «Обо мне» → «Пригласи подруг» и кнопка в сообщении на 20 приглашённых.

### Личные сообщения от бота (`lib/nudges.js`) — в 11:00 МСК, с 27.10.2026 (старт проекта)
